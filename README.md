# GTM Server Tag Template: Zeotap Server-Side Pixel

## Getting Started

This custom tag template is the **Zeotap Server-Side Pixel** for Server-Side Google Tag Manager (sGTM).

It is designed to send the data object you configure directly to Zeotap. The structure of the data within the tag is completely open, meaning you have the flexibility to send anything you like.

> **Important:** Make sure that the data payload you configure in this tag is perfectly aligned with the data schema set up in your Zeotap account.

---

## How to Set It Up

Follow these steps to import and use the template in your sGTM container:

1. Open your Server-Side Google Tag Manager workspace.
2. Navigate to **Templates** in the left-hand menu.
3. Under the _Tag Templates_ section, click the **New** button.
4. Click the **three dots** (More Actions menu) in the top right corner.
5. Select **Import** and upload the `.tpl` file located in this repository.
6. Click **Save** (leave all imported settings exactly as they are).

You are all set! You can now navigate to your **Tags** section and create a new Zeotap tag just like you would with any native GTM tag.
