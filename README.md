# GTM Server Tag Template: Zeotap Server-Side Pixel

## Getting Started

This custom tag template is the **Zeotap Server-Side Pixel** for Server-Side Google Tag Manager (sGTM).

It is designed to send the data object you configure directly to Zeotap. The structure of the data within the tag is completely open, meaning you have the flexibility to send anything you like.

> **Important:** Make sure that the data payload you configure in this tag is perfectly aligned with the data schema set up in your Zeotap account.
